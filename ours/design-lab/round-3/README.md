# Kanosena design lab, round 3

Our own design exploration (not upstream code). Fifteen brand directions on one
standard board each, for blind persona testing with Codex.

- `boards/` one PNG per direction (d01 to d15)
- `kanosena-design-lab-round-3.pdf` all boards, one per page
- `design-lab.html` the source page the boards were rendered from
- `CODEX_PROMPT.md` the test prompt (personas, criteria, scoring, output format)
- `../results/round-3/` where Codex saves its scores and `summary.md`

d01 to d10 are new in round 3. d11 and d12 come from round 2, d13 to d15 from round 1.
The bakery shown on every board is a made-up sample customer.
