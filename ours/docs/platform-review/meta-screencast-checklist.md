# Meta screencasts: record them yourself

Four short videos for Meta App Review. About 20 minutes of recording, plus an hour's wait before video 3.

## Before you start

- [ ] Save the test image [kanosena-meta-test-image.png](assets/kanosena-meta-test-image.png) to Downloads.
- [ ] Open Chrome in a fresh window. Close other tabs, hide the bookmarks bar, set zoom to 100%, and make the window big (at least 1920×1080 if your screen allows it).
- [ ] Log in to https://app.kanosena.com as review@steadylamp.com **before** recording, so the password never shows.
- [ ] Make sure you're logged in to Facebook in the same Chrome window.
- [ ] Turn on Do Not Disturb, so no notifications pop up.

**Text to use (copy exactly):**
- Post text: `Test post from Kanosena: please ignore.`
- First comment: `First comment from Kanosena: please ignore.`
- Image: kanosena-meta-test-image.png

## How to record each video

1. Open QuickTime Player, then File → New Screen Recording.
2. Click **Options**, and set Microphone to **None** (no sound).
3. Choose "Record Selected Portion" and drag it over the Chrome window. Click **Record**.
4. Do the steps below. Go slowly, and pause about a second on each screen.
5. Click the stop button in the menu bar. Then File → Save as `kanosena-meta-video-N` in Downloads (N is the video number).

Captions are optional. The reviewer instructions already explain each step.

## Video 1: connect the Facebook Page (about 1 minute)

Start recording on the Kanosena calendar.
- [ ] Click **Add Channel**, then **Facebook Page**.
- [ ] Facebook's dialog opens. If it offers **Edit access** or **Edit settings**, click it so the Page list and permissions are shown. Keep the Kanosena Page ticked, then **Continue / Save**.
- [ ] Back in Kanosena, choose the **Kanosena** Page. It shows in the left sidebar.
- Stop and save as `kanosena-meta-video-1`.

(This reconnects the Page you already have, so it updates in place without adding a new channel.)

## Video 2: post to Facebook with a first comment (about 2 minutes)

This publishes a real post on the Kanosena Facebook Page. Recording it is your approval.

Start recording on the Kanosena calendar.
- [ ] Click **Create Post**. Select only the **Facebook** (Kanosena Page) avatar at the top.
- [ ] Paste the post text. Click **Insert Media** and add kanosena-meta-test-image.png.
- [ ] Click **Add comment** and paste the first comment.
- [ ] Click **Post now**. Wait for the post to show as published in the calendar.
- [ ] Open a new tab and go to the Kanosena Page on facebook.com. Show the post, and the comment under it from the Page.
- Stop and save as `kanosena-meta-video-2`.

## Video 3: results (record at least 1 hour after video 2, about 1 minute)

Start recording on the Kanosena calendar.
- [ ] Click the Facebook post from video 2 to open it (**Preview**), then **Statistics**. Let the numbers show for a few seconds.
- [ ] Close it, and click **What worked** in the left menu. Scroll to show the Facebook post's results.
- Stop and save as `kanosena-meta-video-3`.

If Statistics is empty, wait another hour and try again.

## Video 4: Instagram (about 3 minutes; the last part is after an hour)

This publishes a real post on the kanosena.app Instagram account.

Start recording on the Kanosena calendar.
- [ ] Click **Add Channel**, then **Instagram (Facebook Business)**. Go through Facebook's dialog (click **Edit access** if offered) and allow. Choose **kanosena.app**. It updates in place.
- [ ] Click **Create Post**. Select only the **Instagram** avatar.
- [ ] Paste the post text, add kanosena-meta-test-image.png with **Insert Media**, then **Add comment** and paste the first comment.
- [ ] Click **Post now**. Wait until it shows as published.
- [ ] Open instagram.com/kanosena.app in a new tab. Open the post and show the comment.
- Stop recording, but **don't save yet**. Instead, after an hour, record a second short clip: open the Instagram post in the calendar → **Statistics**, then **What worked**.
- Save the first part as `kanosena-meta-video-4` and the second as `kanosena-meta-video-4b`. (Or join them in QuickTime: open part 1, then Edit → Add Clip to End, and save as `kanosena-meta-video-4`.)

## When you're done

- [ ] Downloads should have `kanosena-meta-video-1.mov` to `-4.mov`. QuickTime saves .mov, and Meta accepts it.
- [ ] Tell Claude they're ready. The App Review Chrome prompt (`chrome-meta-app-review-submit.txt`) then attaches them, and stops before Submit.
- You can delete the two test posts after Meta approves the app, not before.
